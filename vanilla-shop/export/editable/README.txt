NATURAL VANILLA TEA - EDITABLE ARTWORK
======================================

1. Install the fonts first (folder "fonts"):
   Windows: right-click each .ttf > Install for all users
   Mac:     double-click each .ttf > Install Font
   - Fraunces 144pt SuperSoft Wonky (Italic, SemiBold) - headings and product name
   - Geist (Regular, Medium)                            - body copy and labels
   All are free fonts under the SIL Open Font License, fine for commercial packaging.

2. Open natural-vanilla-tea_EDITABLE.svg in Illustrator (File > Open).

3. Save it straight away as an Illustrator file: File > Save As > Adobe Illustrator (.ai).
   Work in the .ai from then on.

What is editable
- All English text is live type: select it with the Type tool and edit.
- Each panel is its own group: Front, Side_How_to_brew, Back, Side_Whats_inside, Top, Base.
- Cut and fold lines are in the group "Dieline". Move it to its own layer, lock it,
  and set its stroke to the spot colour your printer asks for.
- Illustrations are embedded images.

Kept as outlines on purpose
- Sinhala and Tamil batch labels (complex script; needs a native-reader check before editing).
- The barcode (EAN-13 4796034220229 - placeholder from the 25-bag pack; replace with the
  12-bag pack's own GTIN).
- The Vanilla Shop logo and Ceylon Tea lion (traced; swap in the official vector files).

Before print
- Document Color Mode: RGB now; convert to CMYK (or ask the printer to) before sending.
- Ingredients and storage text are still "To be confirmed".
