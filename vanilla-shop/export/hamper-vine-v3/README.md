# Christmas hamper box: lid artwork

Box 14.5 × 9 × 4.5 in (368.3 × 228.6 × 114.3 mm). Rigid lift-off lid, assumed 3.5 in deep, leaving 1 in of the base
showing below it; change `LID_D` in `tools/hamper/vine/hamper_sides.py` if the box maker's lid depth differs.

The sides are seen foreshortened and, when the box is stacked, shelved or wrapped, instead of the top, so each long
side carries the logo and name, each end the logo; the vine stops short of the corners, where the wrap folds and
wears, and the double rule carries round them.

Fonts: Instrument Serif Italic (`InstrumentSerif-Italic`, OFL, `fonts/instrument-serif-italic.ttf`). Each line of
type is one live text object. The logo is the traced mock-up: replace with the master. Gold (#C9A76A) is meant as
foil; a foil separation is still to be made. Generated by `tools/hamper/vine/draw_hamper_v3.py` and `hamper_sides.py`.
